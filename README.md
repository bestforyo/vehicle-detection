# 鉴见 · 车辆检测工作台

面向车辆检测机构的响应式检测师端原型，覆盖乘用车、摩托车的订单创建、现场检测、机构审核与只读报告分享。首页摩托车检测入口暂时关闭并显示“正在建设中，敬请期待”；已存在的摩托车订单仍可查看和处理。点击乘用车检测后进入独立的订单创建页面：先选国标/团标，再选三非排查、四非排查、整车检测或新车检测；选择后立即创建订单并开始检测。新能源检测入口同样显示“正在建设中，敬请期待”且不可创建。

## 本地运行

```powershell
npm.cmd install
npm.cmd run dev
```

构建校验：`npm.cmd run build`

## 原型流程

1. 首页乘用车入口可用，点击后进入完整创建流程，按“选择标准 → 选择检测类型”操作；选择可用检测类型后立即创建订单并开始检测，不再经过方案确认页。首页摩托车入口暂时禁用并提示“正在建设中，敬请期待”，不会创建摩托车订单；已有摩托车订单仍可查看和继续处理。
2. 乘用车国标和团标下均展示三非排查、四非排查、整车检测、新车检测；新能源检测入口暂时关闭并显示“正在建设中，敬请期待”，不会进入订单创建。
3. 团标整车检测已配置十个模块，共 180 项：漆面覆盖 19 项、重大事故检测 59 项、泡水检测 29 项、火烧检测 8 项、全车玻璃 12 项、内饰检测 24 项、OBD系统诊断 5 项、车辆里程数读取 6 项、发动机及变速箱检测 8 项、底盘检查 10 项。漆面覆盖按塑料件/金属件使用不同车况选项，并分别以黑色/绿色显示选项；检测项顺序保持不变。国标整车检测使用国标重大事故清单，并复用团标整车其余九个模块，共 160 项。国标三非、四非分别复用国标整车中的四个模块（95 项）和五个模块（101 项）；国标新车复用六个国标整车模块和团标新车的车况功能性检测，共 138 项。团标三非、四非分别复用整车中的四个模块（115 项）和五个模块（121 项）。
4. 团标整车重大事故检测为 59 项，国标整车重大事故检测为 39 项；关键决定属性仅用于后台判定，检测项目界面不展示“关键决定项/非关键决定项”标签。只有关键项选择非“正常”结果时需要补充“大于30cm×30cm”或“小于30cm×30cm”判定，选项只显示尺寸判定，不附带“事故车/非事故车”标签；大于时弹出“事故车提示”3 秒后在原位置固定展示，并将非正常结果标红，小于时仅记录尺寸并将非正常结果标黄，“正常”标绿。非关键项不要求尺寸判定。关键项漏选尺寸或模板仍有模块未配置时，不允许提交审核。
5. 泡水检测 29 项按项目使用指定结果选项。左前地毯、主驾座椅骨架及滑轨、行李箱底板、副驾座椅骨架及滑轨、右前地毯选“水渍泥沙”时必须补充说明；五项中有三项或以上选择“水渍泥沙”时，现场检测与正式报告先弹出“泡水车提示”3 秒，再在原位置固定展示。
6. 火烧检测 8 项按项目配置选项；烧蚀、熏黑碳化、炙烤融化任一结果会触发“火烧车提示”，正常、拆装、更换、未配备不触发。提示先弹出 3 秒，再在原位置固定展示。
7. 全车玻璃 12 项按指定顺序和专属选项检测；角玻璃、天窗玻璃、其他玻璃另提供“未配备”。
8. 内饰检测 24 项按指定顺序及项目选项检测；遮阳板/化妆镜、中排座椅、左D柱内饰板、右D柱内饰板和右C柱内饰板另提供“未配备”。
9. OBD 系统诊断含气囊故障码、车身稳定系统、其他、刹车系统故障码、娱乐系统故障码五项，均提供“无故障码 / 有故障码”。
10. 车辆里程数读取包含机/电模块里程数据、变速箱模块里程数据、车身模块里程数据、历史云端里程数据、其他里程数据、维保记录里程数据六项；全部提供“数据正常 / 异常数据”，后面三项另提供“此项检测无此服务”。
11. 发动机及变速箱检测包含发动机机爪胶、发动机主体有无拆装、涡轮增压机、发动机有无渗漏油、机油尺液位、水箱冷凝器、空调冷凝器、三元催化器八项，车况选项按项配置；发动机机爪胶选择“自定义”时需要填写说明。
12. 底盘检查包含左前刹车盘（刹车片）、左前减震器、右前刹车盘（刹车片）、右前减震器、左后刹车盘（刹车片）、左后减震器、右后刹车盘（刹车片）、右后减震器、备用轮胎、轮胎轮毂外侧十项，均按项目配置车况选项。
13. 团标新车检测复用整车检测中的漆面覆盖、重大事故检测、全车玻璃、内饰检测、OBD系统诊断、底盘检查六模块，并新增 29 项车况功能性检测，共 158 项；款型年份核对选择“异常”时必须填写差异款型。
14. 选择可用检测类型后立即创建订单并进入对应模板的现场检测。章节页面仅用于逐项填写结果和通过设备照片选择器添加影像，不显示车牌、首次上牌、表显里程或车型录入框。照片会先在浏览器缩小至最长边 1440px，再以 JPEG 质量 0.76 展示。
15. 未填写结果或必填水渍泥沙说明、自定义说明时禁止提交；异常项目必须有照片。提交后状态进入待审核，检测师仅可查看审核进度；只有机构管理员可以通过或填写必填意见退回。
16. 审核通过后生成正式报告预览；分享链接打开 `/r/{报告编号}`，不要求委托人注册或登录。
17. 机构仅有检测师和机构管理员两种业务角色。检测师负责创建、执行和提交检测报告，不能审核、退回或发布；机构管理员专属审核队列和报告审核操作。现场检测手机端将检测项目、结果录入和照片入口按列对齐呈现。
18. 「检测订单」「检测模板」「审核进度/审核中心」「我的」可通过桌面侧栏或手机底部导航访问；创建页面在手机窄屏下适配单列类型卡片、底部导航安全区及 320px 起的视口宽度。

车辆信息查询目前只有 UI 占位，没有请求第三方服务。

## 当前边界

- 这是前端交互原型，不包含服务端、微信小程序原生工程、机构登录、真实 RBAC、多租户隔离或数据库。示例机构和订单均为虚构数据；新增数据仅保存在当前页面内存中。
- 分享报告快照只写入当前浏览器的 `localStorage`，因此适合在同一浏览器演示，不是可部署的跨设备公开链接。路由和分享页仅用于演示无登录查看体验。
- 模板中的项目是用于串联交互的示范项，并非任何标准的完整检查清单或合规判定。正式上线前应按机构授权使用的摩托车规范、GB/T 30323-2013 及乘用车规范逐条核验，导入受版本控制的标准目录，并由专业人员审核项目、判定逻辑和报告用语。
- SVG 车辆图仅为原型示意；只有检测师实际选择上传的图片才是现场照片。

## 生产化建议

- 租户、用户、角色、模板、订单、检测版本、照片、报告分别建模，并以服务端强制 `tenant_id` 隔离。机构角色限定为检测师和机构管理员；管理员账号由平台开通，检测师账号由机构管理员管理。所有审核、退回和报告发布接口均须服务端校验机构管理员身份。
- 检测提交应创建不可变版本；退回修改创建新草稿版本，审核通过发布带审计记录的正式报告版本。公开链接应使用高熵签名令牌，而不是可枚举的订单编号，并支持过期、撤销、访问日志和敏感字段脱敏。
- 将原图上传至对象存储；服务端生成缩略图与多尺寸 WebP/AVIF，报告首屏优先加载缩略图，较大的原图按需加载。生产报告图片应配合 CDN、缓存策略、分段/断点上传和失败重试。
- 第三方车辆查询通过服务端适配器调用，避免把密钥放在小程序/浏览器端，并记录来源、授权范围和查询审计。
